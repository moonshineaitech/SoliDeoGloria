# Marketing & Comms Kit

Drop-in copy for announcing CAB-FF. Edit freely to match your voice.

| File                              | Use for                                            |
|-----------------------------------|----------------------------------------------------|
| `elevator_pitch.md`               | Anywhere you need 1-3 sentences.                   |
| `x_thread.md`                     | X/Twitter launch thread (12 posts).                |
| `linkedin_post.md`                | LinkedIn announcement, longer-form.                |
| `blog_post_intro.md`              | Substack / Medium / company blog opener.           |
| `hacker_news_post.md`             | HN submission title + first comment.               |
| `reddit_christianity_post.md`     | r/Christianity & r/Reformed style post.            |
| `email_announce.md`               | Newsletter / list announcement.                    |
| `post_invite_baselines.md`        | Ask the community to contribute baseline runs.     |
| `press_release.md`                | Short press-release style note.                    |

All copy is CC BY-SA 4.0 like the rest of the project.
